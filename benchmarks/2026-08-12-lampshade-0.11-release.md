# Lampshade 0.11 release validation

Date: 2026-08-12 (America/Chicago)

## Verdict

Lampshade 0.11 is release-ready on the tested WGPU 29 configurations. The
existing six-workload RTX/Vulkan gate found no reproducible regression against
crates.io 0.10.1 after its one failing row was repeated with nine processes.
The new separate-buffer SoA interface passed its physical correctness suites
on NVIDIA Vulkan, Apple Metal, and Intel Vulkan.

## Published-release regression gate

The initial three-process matrix passed 17 of 18 comparisons. The only miss
was 100M full-width key/value sort at 15.9678 ms versus 15.6525 ms (+2.014%),
0.014 percentage points over the 2% budget. The dedicated nine-process recheck
passed at 15.7433 ms versus 15.6773 ms (+0.421%).

Across the other 17 initial rows, changes ranged from -2.320% to +0.904%.
This supports a scoped statement: no regression was detected in reduction,
bounded/full/count-driven key/value sort, exclusive scan, or 50% compaction on
this RTX/Vulkan gate. It is not evidence for every primitive or GPU.

The raw artifacts preserve every sample, process median, adapter identity,
command configuration, and source-manifest hash:

- [initial matrix](2026-08-12-lampshade-0.11-release-initial.json)
- [100M full-width recheck](2026-08-12-lampshade-0.11-release-recheck.json)

Both were measured from clean commit
`55d0375485dcf0ba9523e765c6f3ce76c8209025`. Their 83-file source manifests
share digest `5958426ab9c7369923b3d6117df6edca90eb91e4c21d8b2c8d4c16b46953d78c`.

Hardware was an NVIDIA GeForce RTX 4070 Ti SUPER using Vulkan and NVIDIA
driver 591.86. The harness used identical deterministic inputs and public
resident APIs, included command recording, submission, GPU execution, and
completion wait, and excluded upload and validation readback. Values are
medians of independent process medians.

## SoA validation

The fixed-count, GPU-counted, alias, and same-encoder count-producer tests
passed on:

- NVIDIA GeForce RTX 4070 Ti SUPER / Vulkan;
- Apple M3 Pro / Metal;
- Intel ADL-N integrated graphics / Vulkan, Mesa 25.2.8.

The full non-ignored release library and integration suites also passed on all
three systems. The Metal and Intel runs used commit `4906c45`; `src/`, the SoA
benchmark, and the SoA integration tests are byte-identical between that
commit and the clean 0.11 release commit.

Diagnostic fixed/GPU-counted medians were 5.816/6.286 ms at 1M and
34.627/34.592 ms at 10M on M3 Metal. Intel Vulkan measured 38.152/38.126 ms at
1M and 423.58/432.56 ms at 10M, with enough 10M variance that the difference is
not treated as a regression. These timings characterize the API on portable
backends; they do not claim the bridge beats application-specific native
sorters.

## Other gates and limitations

Formatting, strict all-target/all-feature Clippy, rustdoc with warnings denied,
examples/benches compilation, release tests, harness unit tests, and packaged
crate verification passed. The package contains WGPU 29.0.4.

The portable SoA bridge is a native-WGPU compatibility path, not a browser
readiness claim. Lampshade has a pre-existing `wasm32-unknown-unknown` compile
failure unrelated to this release. Downstream frame-time evidence remains
scene- and hardware-specific.

## Reproduction

```powershell
benchmarks/release-regression/run.ps1 -Backend vulkan -Processes 3 `
  -OutputPath target/release-regression/0.11-clean.json

benchmarks/release-regression/run.ps1 -Backend vulkan `
  -Items 100000000 -Workloads sort_full_width -Processes 9 `
  -OutputPath target/release-regression/0.11-sort100m-recheck.json
```
