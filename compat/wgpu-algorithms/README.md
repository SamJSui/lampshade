# wgpu-algorithms

This package is deprecated. The project was renamed to [`wgpu-primitives`](https://crates.io/crates/wgpu-primitives) beginning with version 0.2.

Replace the dependency:

```toml
[dependencies]
wgpu-primitives = "0.4"
```

Then update Rust imports from `wgpu_algorithms` to `wgpu_primitives`.
