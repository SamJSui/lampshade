# wgpu-primitives

This is the final compatibility release for the crate now named
[`lampshade`](https://crates.io/crates/lampshade). It is deprecated and will
not receive new features.

Replace the dependency:

```toml
[dependencies]
lampshade = "0.8"
```

Then update Rust imports from `wgpu_primitives` to `lampshade`.
